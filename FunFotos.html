Fun Fotos Photo Album Guide

Build Book The build book button takes your default selections and creates a photo album default in your accounts database. Select your layout, background color, and subset of photos using the search feature. This is a great starting point to creating a final product!
Clear This will first give you a warning letting you know that your book will be wiped from your accounts database. This allows you to start fresh with a new built book or from scratch!
Layouts You have the option of having 1, 2, 3, or 4 images per page across your entire album! Select the one you want to build the default book but also change the layout as you go to see which you like best.
Background Color You wil be able to set a constant color across your entire book upon default build but also change the color per individual page spread.
Fit Image We know not all images have the same aspect ratios, so feel free to experiment with fitting your images to the layout squares or letting them retain their original shapes.
Borders Borders are great to allow you to see the fields in which items need to be placed into. Note that when your book is finalized, you should uncheck the borders so your final product is a much nicer souvenir.
Remove Image If you wish to remove an image you placed to either leave that square blank or place a new photo, click on the image you wish to remove, then click the remove button.
Search Database Use search terms to narrow down your set of photos when trying to select from your database. Note that whatever is in the search bar upon a build button call will be the subset used in creating the new book.
